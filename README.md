# Divine Destination Travel

Small-group tours of India for foreign travellers. Airport pickup and drop, hotels, trains, coaches, and local transport are included.

## Stack

- React 19
- TanStack Start / Router
- Tailwind CSS v4
- Vite 8
- Zod + React Hook Form
- Optional Better Auth + PGLite / Postgres

## Pages

- `/` — home
- `/tours` — all itineraries
- `/tours/$slug` — tour detail
- `/how-it-works` — how a departure works
- `/book` — booking form (saves locally in the browser)

## Run locally

```bash
npm install
npm run dev
```

The dev server binds `0.0.0.0:8080`.

Destination photos live under `public/images/` in the original workspace. They were omitted from this first push because of file size.

## Tours

Golden Triangle, Rajasthan palaces, Kerala backwaters, Himalayan foothills, Ganges & Golden Temple, South India temples, Mumbai to Goa, Wildlife trails.
